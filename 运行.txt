在 **`\WZDjango`** 下按顺序执行即可：

### 1. 进入目录并安装依赖（首次或换环境时）
```powershell
source venv/bin/activate
cd G:\github\WZDjango
pip install -r requirements.txt
```
查看端口
ss -tulnp
### 2. 数据库迁移（首次）
```powershell
python manage.py migrate
```

### 3. 创建登录账号（若还没有用户）
```powershell
python manage.py createsuperuser
```
按提示输入用户名和密码。

### 4. 启动开发服务器（外部可访问）
```powershell
python manage.py runserver 0.0.0.0:7443
```

默认地址：**http://127.0.0.1:7443/**  
- 未登录：打开首页会看到登录页  
- 登录后：访问 **http://127.0.0.1:7443/home/** 进入首页  

### 可选：指定端口
```powershell
python manage.py runserver 0.0.0.0:8080
```

### 可选：把 Alphadata 里的 xlsx 导入 MongoDB
先保证本机 **MongoDB** 在 `localhost:27017` 已启动，再执行：
```powershell
python manage.py import_alphadata_xlsx
```

### API（curl 调用）
查询数据：
```powershell
curl "http://127.0.0.1:7443/api/alpha/daily/?date_from=2026-01-01&date_to=2026-01-31&limit=100"
```

上传导入：
```powershell
curl -X POST -F "file=@G:/github/WZDjango/Alphadata/Alpha产品表现汇总_20220921.xlsx" "http://127.0.0.1:7443/api/alpha/import/"
```

### 导入交易日 CSV → MongoDB（alpha_product.trade_calendar）
默认读取项目内 `trade_dates_all/trade_dates_all.csv`：
```powershell
python manage.py import_trade_dates_csv
```
清空后全量导入：
```powershell
python manage.py import_trade_dates_csv --clear
```

### 净值曲线 API
`product_name` 必填。最近 N 个交易日：`recent=5|10|15`（默认 5）；或区间：`date_from` / `date_to`（与 `recent` 二选一，优先 `recent`）。
```powershell
curl "http://127.0.0.1:7443/api/nav/curve/?product_name=产品名称&recent=5&only_trading_days=1"
```
```powershell
curl "http://127.0.0.1:7443/api/nav/curve/?product_name=产品名称&date_from=2024-01-01&date_to=2024-12-31&only_trading_days=1"
```
浏览器页面：**http://127.0.0.1:7443/nav/curve/**（需登录）

### Alpha 日报邮件自动导入（交易日 17:30）
先保证 `trade_calendar` 已导入。配置在项目根目录 **`.env`**：
- IMAP 收件：`ALPHA_MAIL_USER` / `ALPHA_MAIL_PASS` / `ALPHA_IMAP_SERVER` / `ALPHA_IMAP_PORT`
- 结果通知（发到 shenwenhui@wonderwiz.cn、15525171170@163.com）：`ALPHA_NOTIFY_*`、`ALPHA_NOTIFY_TO`
- Mongo：`MONGODB_URI`
```powershell
python manage.py auto_import_alpha_mail
```
Windows 计划任务每日 17:30：程序 `python`，参数 `manage.py auto_import_alpha_mail`，起始于 `G:\github\WZDjango`。详见 `scheduler/README.md`。
按今天日期（并走交易日判断）
python manage.py auto_import_alpha_mail
忽略交易日判断强制执行
python manage.py auto_import_alpha_mail --force
指定某天主题并强制执行
python manage.py auto_import_alpha_mail --force --subject-date 20260415

### 自动启动定时器（随 Django runserver 启动）
默认已开启：启动 Django 即自动后台进入定时循环（无需手动执行额外命令），按每天 `17:30` 触发。


  python manage.py auto_import_fund_nav_mail
  python manage.py auto_import_fund_nav_mail --force
  python manage.py auto_import_fund_nav_mail --nav-date 2026-04-02
