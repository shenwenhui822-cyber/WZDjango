================================================================================
  python manage.py runserver 
  WZDjango 本地 / 服务器运行说明
  项目根目录：<项目>/WZDjango（Windows 示例 G:\github\WZDjango）
================================================================================

【前提】
  - Python 3.x，建议使用项目内 venv
  - MongoDB 默认 localhost:27017（导入类命令需要）
  - 项目根目录配置 .env（由 Django 加载）

--------------------------------------------------------------------------------
一、进入目录并安装依赖（首次或换环境）
--------------------------------------------------------------------------------

  Windows（PowerShell）示例：
    cd G:\github\WZDjango
    .\venv\Scripts\activate
    pip install -r requirements.txt

  Linux / macOS 示例：
    cd /home/Django/WZDjango
    source venv/bin/activate
    pip install -r requirements.txt

--------------------------------------------------------------------------------
二、数据库迁移（首次或模型变更后）
--------------------------------------------------------------------------------

    python manage.py migrate

--------------------------------------------------------------------------------
三、管理员账号（若还没有）
--------------------------------------------------------------------------------

    python manage.py createsuperuser

--------------------------------------------------------------------------------
四、启动开发服务器（局域网可访问）
--------------------------------------------------------------------------------

    python manage.py runserver 0.0.0.0:7443

  浏览器：
    - 未登录：首页会跳转登录
    - 登录后首页：http://127.0.0.1:7443/home/

  换端口示例：
    python manage.py runserver 0.0.0.0:8080

--------------------------------------------------------------------------------
五、查看端口占用（可选）
--------------------------------------------------------------------------------

  Linux：
    ss -tulnp | grep 7443

  Windows（PowerShell）：
    netstat -ano | findstr 7443

六、数据导入（按需）
--------------------------------------------------------------------------------

  6.1 Alphadata xlsx → MongoDB（需 Mongo 已启动）
      python manage.py import_alphadata_xlsx

  6.2 交易日 CSV → MongoDB（alpha_product.trade_calendar）
      默认读取项目内 trade_dates_all/trade_dates_all.csv
      python manage.py import_trade_dates_csv
      清空后全量：
      python manage.py import_trade_dates_csv --clear

  6.3 本地下载目录多行净值表 → fund_nav_real（博士一号等）
      默认目录：项目根 downloaded_attachments_boshiyihao
      python manage.py import_fund_nav_local
      指定目录：
      python manage.py import_fund_nav_local --dir <目录路径>

  6.4 T0 表现相关（MongoDB 库名默认 T0_performance；周度=深度秩序口径，日内=汇祝口径数据来源）
      （1）sync_t0_performance — 从 FTP 拉取「*_wuzhi_日内交易汇总.xlsx」写入集合 daily_report（日内明细）。
          依赖：交易日历已导入；环境变量 T0_FTP_HOST / T0_FTP_PORT / T0_FTP_USER / T0_FTP_PASSWORD /
          T0_FTP_REMOTE_DIR / T0_FTP_XLSX_SUFFIX（见 settings，可用 .env 覆盖）。
          手动执行：
            python manage.py sync_t0_performance
          内置定时：见第九节 16:30（仅交易日）；关闭：T0_FTP_SYNC_SCHEDULER_ENABLED=0。

      （2）import_qichat_t0_orders — 仅扫描本地目录下 *.csv 导入集合 t0_order（周度绩效），不连邮箱。
          默认目录：项目根 qichat（settings.T0_QICHAT_IMPORT_DIR）。
            python manage.py import_qichat_t0_orders
            python manage.py import_qichat_t0_orders --dir <目录路径>

      （3）auto_import_qichat_t0_mail — 邮箱 IMAP 按「动态主题」下载 CSV 到 qichat；入库时仅处理本次新保存的附件，不重复扫描目录内其它 CSV。
          邮箱：.env 中 ALPHA_MAIL_USER / ALPHA_MAIL_PASS（及 ALPHA_IMAP_SERVER、ALPHA_IMAP_PORT）。
          主题：默认前缀 settings.T0_QICHAT_MAIL_SUBJECT_PREFIX（可用环境变量覆盖），完整主题为
                {前缀}{上一自然周内首个交易日YYYYMMDD}_{同周内末个交易日YYYYMMDD}
                示例：吾执_周度绩效_20260420_20260424（与收件箱主题完全一致才会命中）。
          手动执行：
            python manage.py auto_import_qichat_t0_mail
            python manage.py auto_import_qichat_t0_mail --ref-date 2026-05-11
            python manage.py auto_import_qichat_t0_mail --subject "吾执_周度绩效_20260420_20260424"
          内置定时：见第九节 20:00（仅每周首个交易日）；关闭：T0_QICHAT_WEEKLY_SCHEDULER_ENABLED=0。

--------------------------------------------------------------------------------
七、HTTP API（curl 示例，端口按实际修改）
--------------------------------------------------------------------------------

  查询 Alpha 日数据：
    curl "http://127.0.0.1:7443/api/alpha/daily/?date_from=2026-01-01&date_to=2026-01-31&limit=100"

  上传 Alpha xlsx：
    curl -X POST -F "file=@<本地xlsx路径>" "http://127.0.0.1:7443/api/alpha/import/"

  净值曲线 API（product_name 必填）
    最近 N 个交易日（recent=5|10|15，默认 5）：
    curl "http://127.0.0.1:7443/api/nav/curve/?product_name=产品名称&recent=5&only_trading_days=1"
    日期区间（与 recent 二选一，优先 recent）：
    curl "http://127.0.0.1:7443/api/nav/curve/?product_name=产品名称&date_from=2024-01-01&date_to=2024-12-31&only_trading_days=1"

  净值曲线页面（需登录）：
    http://127.0.0.1:7443/nav/curve/
