================================================================================
  WZDjango 本地 / 服务器运行说明
  项目根目录：<项目>/WZDjango（Windows 示例 G:\github\WZDjango）
================================================================================

【前提】
  - Python 3.x，建议使用项目内 venv
  - MongoDB 默认 localhost:27017（导入类命令需要）
  - 项目根目录配置 .env（由 Django 加载）

--------------------------------------------------------------------------------
一、进入目录并安装依赖（首次或换环境）
--------------------------------------------------------------------------------

  Windows（PowerShell）示例：
    cd G:\github\WZDjango
    .\venv\Scripts\activate
    pip install -r requirements.txt

  Linux / macOS 示例：
    cd /home/Django/WZDjango
    source venv/bin/activate
    pip install -r requirements.txt

--------------------------------------------------------------------------------
二、数据库迁移（首次或模型变更后）
--------------------------------------------------------------------------------

    python manage.py migrate

--------------------------------------------------------------------------------
三、管理员账号（若还没有）
--------------------------------------------------------------------------------

    python manage.py createsuperuser

--------------------------------------------------------------------------------
四、启动开发服务器（局域网可访问）
--------------------------------------------------------------------------------

    python manage.py runserver 0.0.0.0:7443

  浏览器：
    - 未登录：首页会跳转登录
    - 登录后首页：http://127.0.0.1:7443/home/

  换端口示例：
    python manage.py runserver 0.0.0.0:8080

--------------------------------------------------------------------------------
五、查看端口占用（可选）
--------------------------------------------------------------------------------

  Linux：
    ss -tulnp | grep 7443

  Windows（PowerShell）：
    netstat -ano | findstr 7443

--------------------------------------------------------------------------------
六、数据导入（按需）
--------------------------------------------------------------------------------

  6.1 Alphadata xlsx → MongoDB（需 Mongo 已启动）
      python manage.py import_alphadata_xlsx

  6.2 交易日 CSV → MongoDB（alpha_product.trade_calendar）
      默认读取项目内 trade_dates_all/trade_dates_all.csv
      python manage.py import_trade_dates_csv
      清空后全量：
      python manage.py import_trade_dates_csv --clear

  6.3 本地下载目录多行净值表 → fund_nav_real（博士一号等）
      默认目录：项目根 downloaded_attachments_boshiyihao
      python manage.py import_fund_nav_local
      指定目录：
      python manage.py import_fund_nav_local --dir <目录路径>

--------------------------------------------------------------------------------
七、HTTP API（curl 示例，端口按实际修改）
--------------------------------------------------------------------------------

  查询 Alpha 日数据：
    curl "http://127.0.0.1:7443/api/alpha/daily/?date_from=2026-01-01&date_to=2026-01-31&limit=100"

  上传 Alpha xlsx：
    curl -X POST -F "file=@<本地xlsx路径>" "http://127.0.0.1:7443/api/alpha/import/"

  净值曲线 API（product_name 必填）
    最近 N 个交易日（recent=5|10|15，默认 5）：
    curl "http://127.0.0.1:7443/api/nav/curve/?product_name=产品名称&recent=5&only_trading_days=1"
    日期区间（与 recent 二选一，优先 recent）：
    curl "http://127.0.0.1:7443/api/nav/curve/?product_name=产品名称&date_from=2024-01-01&date_to=2024-12-31&only_trading_days=1"

  净值曲线页面（需登录）：
    http://127.0.0.1:7443/nav/curve/

--------------------------------------------------------------------------------
八、邮件自动导入管理命令（手动执行）
--------------------------------------------------------------------------------

  说明：交易日历需已导入（import_trade_dates_csv），否则“是否交易日”判断可能异常。

  --- Alpha 日报（IMAP 用 .env：ALPHA_MAIL_USER / ALPHA_MAIL_PASS 等）---
    python manage.py auto_import_alpha_mail
    python manage.py auto_import_alpha_mail --force
    python manage.py auto_import_alpha_mail --force --subject-date 20260415

  --- 博士一号真实净值（同上 ALPHA_MAIL_*）---
    python manage.py auto_import_fund_nav_mail
    python manage.py auto_import_fund_nav_mail --force
    python manage.py auto_import_fund_nav_mail --nav-date 2026-04-02

  --- 泽鑫多维 ZXDW 净值邮件（IMAP 用 .env：FARPORT_MAIL_USER / FARPORT_MAIL_PASS）---
    可选：ALPHA_IMAP_SERVER、ALPHA_IMAP_PORT（默认 imap.exmail.qq.com:993）
    python manage.py auto_import_zxdw_nav_mail
    python manage.py auto_import_zxdw_nav_mail --force
    python manage.py auto_import_zxdw_nav_mail --report-date 2026-04-17

  --- 五矿期货结算单（IMAP 用 .env：FARPORT_MAIL_USER / FARPORT_MAIL_PASS）---
    python manage.py auto_import_wkqh_settle_mail
    python manage.py auto_import_wkqh_settle_mail --subject-date 2026-04-20
    python manage.py auto_import_wkqh_settle_mail --subject-date 2026-04-20 --days 7
    兼容命令（等价）：
    python manage.py wkqh_settle_service
    python manage.py wkqh_settle_service --subject-date 2026-04-20

  --- 长江期货结算单（IMAP 用 .env：FARPORT_MAIL_USER / FARPORT_MAIL_PASS）---
    主题格式：81801575-吾执泽鑫多维-长江期货-YYYYMMDD
    附件格式：81801575-吾执泽鑫多维-YYYYMMDD.rar
    落库配置在 settings：
    MONGODB_CJQH_SETTLE_DB / MONGODB_CJQH_SETTLE_COLLECTION
    python manage.py auto_import_cjqh_settle_mail
    python3 manage.py auto_import_cjqh_settle_mail --subject-date 2026-04-17
    python manage.py auto_import_cjqh_settle_mail --subject-date 2026-04-17 --days 7
    兼容命令（等价）：
    python manage.py cjqh_settle_service
    python manage.py cjqh_settle_service --subject-date 2026-04-17

  结果通知邮件（SMTP）：.env 中 ALPHA_NOTIFY_*、ALPHA_NOTIFY_TO

--------------------------------------------------------------------------------
九、内置定时任务（随 Django 进程启动，见 portal.scheduler.alpha_mail_scheduler）
--------------------------------------------------------------------------------

  默认排期（本地时区，可通过环境变量关闭单项任务，见代码内 *_SCHEDULER_ENABLED）：
    09:30  update_rq_bench
    09:31  auto_import_fund_nav_mail
    12:00  auto_import_zxdw_nav_mail
    17:30  auto_import_alpha_mail
    18:00  auto_import_wkqh_settle_mail
    18:00  auto_import_cjqh_settle_mail

  说明：使用 runserver 或部署 ASGI/WSGI 且加载了该 scheduler 时，后台线程按上述时间
        调用对应 manage.py 命令。若仅需要“手动跑任务”，可直接执行第八节命令。

--------------------------------------------------------------------------------
十、Windows 计划任务示例（不依赖 Django 常驻时）
--------------------------------------------------------------------------------

  程序：python（或 venv 内 python.exe）
  参数：manage.py auto_import_alpha_mail
  起始于：项目根目录（如 G:\github\WZDjango）
  触发：每日 17:30（与业务约定一致时）
