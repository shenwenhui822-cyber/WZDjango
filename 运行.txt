================================================================================
  WZDjango 本地 / 服务器运行说明
  项目根目录：<项目>/WZDjango（Windows 示例 G:\github\WZDjango）
================================================================================

【前提】
  - Python 3.x，建议使用项目内 venv
  - MongoDB 默认 localhost:27017（导入类命令需要）
  - 项目根目录配置 .env（由 Django 加载）

--------------------------------------------------------------------------------
一、进入目录并安装依赖（首次或换环境）
--------------------------------------------------------------------------------

  Windows（PowerShell）示例：
    cd G:\github\WZDjango
    .\venv\Scripts\activate
    pip install -r requirements.txt

  Linux / macOS 示例：
    cd /home/Django/WZDjango
    source venv/bin/activate
    pip install -r requirements.txt

--------------------------------------------------------------------------------
二、数据库迁移（首次或模型变更后）
--------------------------------------------------------------------------------

    python manage.py migrate

--------------------------------------------------------------------------------
三、管理员账号（若还没有）
--------------------------------------------------------------------------------

    python manage.py createsuperuser

--------------------------------------------------------------------------------
四、启动开发服务器（局域网可访问）
--------------------------------------------------------------------------------

    python manage.py runserver 0.0.0.0:7443

  浏览器：
    - 未登录：首页会跳转登录
    - 登录后首页：http://127.0.0.1:7443/home/

  换端口示例：
    python manage.py runserver 0.0.0.0:8080

--------------------------------------------------------------------------------
五、查看端口占用（可选）
--------------------------------------------------------------------------------

  Linux：
    ss -tulnp | grep 7443

  Windows（PowerShell）：
    netstat -ano | findstr 7443

--------------------------------------------------------------------------------
六、数据导入（按需）
--------------------------------------------------------------------------------

  6.1 Alphadata xlsx → MongoDB（需 Mongo 已启动）
      python manage.py import_alphadata_xlsx

  6.2 交易日 CSV → MongoDB（alpha_product.trade_calendar）
      默认读取项目内 trade_dates_all/trade_dates_all.csv
      python manage.py import_trade_dates_csv
      清空后全量：
      python manage.py import_trade_dates_csv --clear

  6.3 本地下载目录多行净值表 → fund_nav_real（博士一号等）
      默认目录：项目根 downloaded_attachments_boshiyihao
      python manage.py import_fund_nav_local
      指定目录：
      python manage.py import_fund_nav_local --dir <目录路径>

--------------------------------------------------------------------------------
七、HTTP API（curl 示例，端口按实际修改）
--------------------------------------------------------------------------------

  查询 Alpha 日数据：
    curl "http://127.0.0.1:7443/api/alpha/daily/?date_from=2026-01-01&date_to=2026-01-31&limit=100"

  上传 Alpha xlsx：
    curl -X POST -F "file=@<本地xlsx路径>" "http://127.0.0.1:7443/api/alpha/import/"

  净值曲线 API（product_name 必填）
    最近 N 个交易日（recent=5|10|15，默认 5）：
    curl "http://127.0.0.1:7443/api/nav/curve/?product_name=产品名称&recent=5&only_trading_days=1"
    日期区间（与 recent 二选一，优先 recent）：
    curl "http://127.0.0.1:7443/api/nav/curve/?product_name=产品名称&date_from=2024-01-01&date_to=2024-12-31&only_trading_days=1"

  净值曲线页面（需登录）：
    http://127.0.0.1:7443/nav/curve/
